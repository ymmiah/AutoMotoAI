# Studio version notes

Every studio grows in small, reviewed versions. Each page below explains what one
version added, what it deliberately does not do, and how it was tested. For a short
summary of each release, see the [changelog](https://github.com/ymmiah/AutoMotoAI/blob/main/CHANGELOG.md).

New to the studios? Start with [Studios the assistant can use](STUDIO-ASSISTANT.md).
