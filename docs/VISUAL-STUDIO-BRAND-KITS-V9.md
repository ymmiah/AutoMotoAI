# Visual Studio v9 — Brand kits

Development only. Microsoft Store publication remains paused.

Brand kits contain validated colours, heading/body sizes, and an optional reference to an existing original uploaded logo. Save, load and delete kits privately per workspace. Apply to one or all pages with whole-document preflight validation, preserve manual styles, exact copy and original images, and use page-scoped Undo. Additional templates: Brand launch and Executive brief. See tests/test_visual_brand_kits.py and apps/desktop/test/visual-brand-kits.cjs for safeguards.
