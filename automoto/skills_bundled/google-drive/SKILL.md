# Google Drive

1. Settings → Connectors → **Google Drive** → Enable (Google's hosted MCP server via `mcp-remote`; sign in with Google).
   Some Google accounts need a Workspace or Cloud project to allow it.
2. Search first (by name/type/owner), then read the file. Large files: ask for a summary of the parts you need.
3. Downloads go into the working folder; uploads, sharing and deleting always ask for approval.
4. No connector? The user can download the file and drop it into the workspace, or sync a folder and add it in Settings → Files.
