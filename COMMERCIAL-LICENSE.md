* **personal use**, on your own computers or your own server;

The AGPL's main conditions, in plain words (the [licence text](LICENSE) is what counts):

* If you give copies to others (changed or not), you must give them the source code under the AGPL too.
* If you **change it and let people use it over a network** (for example as a hosted website or service), you must
  offer those users the source code of your changed version. AutoMoto's web interface has a **Source code** link for
  this; point it at your version with `AUTOMOTO_SOURCE_URL`.

A commercial licence can cover, for example:
