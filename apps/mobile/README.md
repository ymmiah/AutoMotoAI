# AutoMoto AI — Mobile app (Flutter · Android + iOS)

Status: **scaffold** — Dart sources + bootstrap script. Platform folders are generated by
`flutter create` so they always match your Flutter version. Not store-ready.

## What it does
- **Chat** with the AutoMoto v4 router (auto-failover, shows which AI answered / what it switched from)
- **AIs** tab: live provider status and which ones understand images (👁)
- **Keys** tab: server URL, `AUTOMOTO_API_TOKEN`, and optional BYOK provider keys stored in the
  iOS Keychain / Android Keystore (`flutter_secure_storage`). "Forget everything" wipes them.
- **Vision attach**: camera or photo library → routed only to vision-capable AIs

What it does **not** do: desktop automation. Phones can't (and shouldn't) drive your PC; the
server never offers desktop actions to `client: "mobile"`.

## Run
1. On your PC (same Wi-Fi, or a VPN such as Tailscale):
   ```bash
   export AUTOMOTO_API_TOKEN=$(python -c "import secrets;print(secrets.token_urlsafe(24))")
   echo $AUTOMOTO_API_TOKEN       # paste this into the app's Keys tab
   python -m automoto serve --host 0.0.0.0 --no-browser
   ```
2. In `apps/mobile` (Flutter 3.22+):
   ```bash
   ./tool/bootstrap.sh            # flutter create + Android cleartext/INTERNET + iOS camera/photo/ATS keys
   flutter run                    # Android emulator/device
   open ios/Runner.xcworkspace    # iOS: set your signing team in Xcode, then run
   ```
3. In the app's **Keys** tab set the server URL (`http://10.0.2.2:8765` on the Android
   emulator, `http://<PC-LAN-IP>:8765` on a real phone) and the token.

Plain HTTP is only meant for your own LAN. For anything wider, put the server behind HTTPS
(e.g. Tailscale Serve / a reverse proxy) and use an `https://` URL.
