# Changelog

## 5.6.0 (pre-release, part of AutoMoto AI 5.6.0-beta.3)
- Packaged as `automoto-ai-5.6.0-beta.3.vsix`. An empty chat shows idea buttons (Explain this project, Fix a bug,
  Write tests, Summarise a file, Make a Word report, Research a topic) instead of asking you to know tool names.
- Steps and approval prompts use plain words (*Reading your slides*, *AutoMoto wants to: Writing your Word
  document*), with a line saying what the assistant is working with. The engine now picks the tools per task.

## 5.6.0 (pre-release, part of AutoMoto AI 5.6.0-beta.2)
- Repackaged as `automoto-ai-5.6.0-beta.2.vsix` with the beta 2 engine fixes (model fallback, clearer AI errors,
  sturdier tool calls). The panel itself is unchanged.

## 5.6.0 (pre-release, part of AutoMoto AI 5.6.0-beta.1)
- Packaged as a VS Code **pre-release** (`automoto-ai-5.6.0-beta.1.vsix`). Version in step with the AutoMoto AI
  5.6.0 beta (one account everywhere, the Windows app). The panel itself is unchanged.

## 5.5.0
- Marketplace / Open VSX ready: gallery banner, pricing, issue links; version in step with AutoMoto AI 5.5.0.
- Works with the AutoMoto AI local server (single-user). Hosted multi-user servers are for the web GUI only.

## 5.4.0
- Version in step with AutoMoto AI 5.4.0 (data files, archives, WordPress tools).

## 5.2.0
- First release: chat view, ask about selection, fix diagnostic (quick fix), explain file, run agent task on workspace, approvals as modal dialogs.
