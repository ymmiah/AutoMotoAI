# Age rating (IARC questionnaire)

Partner Center → your app → submission → **Age ratings**. Pick the category **"App (not a game)"** and answer
honestly. The questions are worded by IARC and may differ a little; these are the facts to answer them with.

| Topic | Answer | Why |
|---|---|---|
| Violence, fear, sexual content, nudity, bad language, drugs, alcohol, tobacco, gambling, crude humour | **No** | the app ships no such content |
| Does the app show content made by **generative AI** in response to user input? | **Yes** | the chat replies and documents come from the AI model the user picks |
| Can users **interact or exchange content with other users** (chat, messaging, sharing)? | **No** | there's no messaging between users; an account server only keeps each user's own chats |
| Does the app give **unrestricted internet access** (browse or search the web)? | **Yes** | web research opens search results and web pages the user asks for |
| Does it share the user's **location** with others? | **No** | it never reads location |
| **Digital purchases** / in-app purchases? | **No** | free, nothing sold in the app |
| Does it collect personal information shared with third parties? | Answer **Yes** if asked broadly: messages go to the AI provider the user chooses | see the privacy policy |

Expected result: a low-to-teen rating with interactive elements such as *Unrestricted Internet* (and possibly a
generative-AI note). The exact rating is set by IARC after you submit; don't pick a rating yourself.
Store policy 11.11 requires the answers to stay accurate when the app changes.
